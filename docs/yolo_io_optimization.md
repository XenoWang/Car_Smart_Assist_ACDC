# 检测输入输出等价提速

本次只减少检测适配层的数据转换与结果传输，不更换模型或后处理算法。

- 公共图像输入仍先规范化为 RGB uint8；随后一次构造独立、连续的 BGR 数组，交给既有预测入口。Ultralytics 的数组入口按 BGR 解释，不能直接传 RGB。
- 检测框整体传到 CPU 后，读取原有坐标、分数和类别，避免分别传输三个字段。输出顺序、精度、空框和公开字段保持原合同。
- 默认输入分辨率、权重、校准、模型精度、类别阈值和非极大值抑制规则不变。不改调用方像素，不在公共入口静默跳过校验。

## 速度比较

固定38图、同一CUDA设备、batch1，每次预热2遍、稳态5遍。采用三组独立进程配对，顺序为旧新、新旧、旧新。每组记录完整管线的平均耗时、吞吐和P95/P99；正常测速不加阶段插桩。

为满足跨进程全管线逐位对照，双方比较worker共同使用seed42、确定性算法/cuDNN、关闭cuDNN benchmark及CUBLAS_WORKSPACE_CONFIG=:4096:8。生产默认设置不变；该控制可能影响算法选择和绝对耗时，结果仅在双方相同条件下比较。

在输出一致的前提下，完整管线有可重复的有效提速即可判阶段性成功，不要求本轮必须达到30帧。判定预先固定为：

1. 三组预解码稳态平均耗时均下降。
2. 三组总体平均耗时相对改善，大于旧组三次平均耗时的相对极差。
3. 新组平均P95的增加，不超过旧组三次P95的极差。

低于该保守波动界限时标为证据不足；速度、尾延迟与输出等价分别报告。该三组协议不等于置信区间或实车验证。文件输入结果也须公开，不能只挑最快一次；不得用旧单次27.27帧直接对比不同环境的新一次结果。
