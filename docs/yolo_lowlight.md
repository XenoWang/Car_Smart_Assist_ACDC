# YOLO11n 低照度短程对照

样例审查使用17张训练代表图和102个像素视图，选取0.5曝光、0.001信号相关噪声系数及0.001线性读噪声标准差作为保守起点。训练候选只作用于原图均值至少80/255且元数据为非夜间的训练图，并按每轮固定的选择表实施。原有夜间训练图正常参与训练。强度来自本次样例审查，实际识别收益待配对结果确定。

配置生成入口为

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/prepare_yolo_lowlight_pair.py --preview-run artifacts/reports/yolo_lowlight_preview_20261106/attempt-kt8xq9ij --output-dir artifacts/experiments/yolo_lowlight_20261106/recipe20
```

本机已生成该目录。重新准备时使用新的输出目录。control.yaml 和 lowlight.yaml 都从同一初始BCE权重创建独立训练器，分别训练20轮，960、batch4、seed42、FP32、关闭早停。单独的计划文件绑定数据签名、参数、可选训练帧及20轮选择列表。共有1746个可选帧，每轮选择436张，总计8720次计划曝光。

额外图像变换在训练批次进入模型前应用，按原始帧尺寸计算实际图像区域。原生HSV已完成，候选的线性化曝光与噪声随后应用，使用按轮次、源帧和固定种子推导的独立随机流。批次像素先复制后更改；标签、区域掩码和填充区由原流程处理。候选只能通过显式training_lowlight配方启用，恢复/选模身份绑定模式与计划摘要。

两组都记录实际图数、批次数、优化器更新数、选择数、应用数和源帧顺序摘要。完整训练应分别达到38280张、9580批；两组选择均为8720次，control应用0次，lowlight应用8720次。校准使用各自模型和同一313张校准图，最终在289张完整原图上比较九类与交通八类AP、障碍物标注区域AP、夜间及障碍物尺度召回和逐类误报漏报。运行时对子进程统一设置PIN_MEMORY=false。首次筛选为单种子20+20轮，是否值得扩展训练由实测决定。

训练入口继续使用scripts/train_detection.py，配对命令为独立审批的前台验收。每次输出独立目录和controls.json，包含使用原配置和同一STOP文件的停止命令。手动停止后不自动启动后续模型。
