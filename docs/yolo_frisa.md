# YOLO11n P4 FRISA 实验

本地实现依据 Fog-YOLO11n 第3.3节公式16–34，在当前原生YOLO11n第19层C3k2输出之后进行特征调制。第19层的输出继续用于P4检测和后续P5融合；原网络24层编号、主干和检测头形状保持兼容。[论文](https://doi.org/10.3390/app16168059)

## 复现选择

论文图3的语义门包含两层卷积和GELU，公式27只有一层。本实现采用公式27。空间门公式26未给出k，采用图3的1×1；三条深度卷积分支为3×3且膨胀率1/2/3。BN使用eps0.001、momentum0.03，分支权重初始为0，新卷积由种子42的局部CPU随机流初始化。这些取舍绑定版本eq16_34_k1_d3_v1。尚未获得作者代码，本地对照检验此版本的迁移效果。

输出为X+X*Sigmoid(BN(Conv(F)))。因该残差门会放大特征幅度，新增模块初始输出与原模型存在差异。验收分别检查公共权重完全迁移和候选前向的正确性。

## 权重与入口

configs/model/yolo_frisa_control.yaml 和 yolo_frisa_trial.yaml 均从当前九类BCE部署权重出发，预设各20轮，960、batch4、seed42、FP32、关闭早停。正式配对运行须使用新的独立输出目录，并单独批准。

原第19层的cv1、cv2、m参数名称保留。新增参数位于model.19.frisa，模型保存frisa_version；配置和选模合同记录版本与mode。训练器从已有候选检查点重建时同时恢复公共参数与FRISA参数。加载候选权重却选择控制组或缺少相应配方时拒绝继续，避免丢失已训练模块。正常预测和评估使用包含模块的已保存模型。

## 首阶段验收

先核对公式的独立数值预期、两路门控与梯度、正常训练器构建、真实权重公共状态、完整模块保存/加载与重复恢复。再检查原生预测入口和GPU单模型前向成本。该模型级计时用于结构预检，完整管线吞吐与识别增益须在短程训练、独立校准和整图验证后测量。未训练的FRISA输出不用于宣称精度改善。
